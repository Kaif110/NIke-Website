# Nike Website 👟

A modern and responsive Nike-inspired website built using **HTML5 and CSS3**.  
This project focuses on creating a clean, stylish, and user-friendly e-commerce interface inspired by Nike's design.

## ✨ Features

- 🏠 Modern homepage layout
- 🧭 Responsive navigation bar
- 👟 Product showcase section
- 💰 Product names and pricing
- 🛍️ Shop Now call-to-action
- 🔍 Search, cart, and menu icons
- 📱 Responsive design
- 🎨 Clean and minimal UI

## 🛠️ Technologies Used

- HTML5
- CSS3

## 📌 Purpose

This project was created to practice **frontend development, responsive web design, CSS layouts, and modern UI styling** using only HTML and CSS.

## 📷 Preview

A Nike-inspired product landing page featuring a limited-edition shoe collection.
